# TU-BS Softwareentwicklungspraktikum

This repository contains a project developed as part of the **Softwareentwicklungspraktikum** at **Technische Universität Braunschweig**.

The project is shared mainly for documentation and demonstration purposes.  
The code may no longer be directly runnable, and I do not intend to actively fix old bugs or update dependencies. The goal of this repository is to preserve and show the work that was done during the practical course.

## Project Overview

In this project, we implemented and compared different data structures:

- lock-free data structures
- lock-based data structures

We also developed a benchmark to compare their performance, mainly for the following operations:

- add
- remove

Because the implementation was written in C, separate code versions were provided for **Windows** and **macOS**.

## Visualization

A simple GUI was built using **JavaFX**.  
The benchmark results were visualized using a Python line chart library.
